# Gobuster

> Ferramenta de enumeração web utilizada para descobrir diretórios e arquivos em servidores web.

## Para que serve?

O Gobuster automatiza a busca por caminhos que podem não estar visíveis na navegação normal de um site. Ele utiliza listas de palavras (*wordlists*) para testar possíveis diretórios e arquivos, ajudando a identificar páginas ocultas e recursos que precisam ser avaliados quanto à exposição indevida.

# Hydra

> Ferramenta de auditoria de credenciais que automatiza testes de autenticação em serviços compatíveis.

## Para que serve?

O Hydra testa combinações de usuários e senhas utilizando listas de credenciais, permitindo avaliar a resistência dos mecanismos de autenticação a senhas fracas e ataques de dicionário. É utilizado em testes de segurança autorizados para identificar possíveis fragilidades na autenticação.
